TwinSwap

A modern, lightweight Solana Web3 swap interface built with HTML, CSS, and JavaScript.

TwinSwap lets users connect a Phantom wallet, view their Solana portfolio, check live token balances and prices, and get live swap quotes through Jupiter liquidity.

🚀 Features

* 🔄 Token swapping interface
* 👻 Phantom wallet connection
* 💰 Solana portfolio tracking
* 📊 Live token balances
* 💵 USD portfolio valuation
* ⚡ Live Jupiter swap quotes
* 🪙 SOL, USDC, USDT, JUP and BONK support
* 🔃 Token switching
* 📱 Responsive modern UI
* 🔒 Non-custodial wallet interaction
* 🔗 Solscan transaction links

🔐 Wallet

TwinSwap uses a non-custodial approach. Users connect their own Phantom wallet and approve transactions themselves.

TwinSwap does not store users’ private keys or seed phrases.

⚙️ Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Start the project with a local web server.
4. Open the website in your browser.
5. Connect Phantom Wallet.
6. Test the swap and portfolio features.

📌 Notes

TwinSwap is a frontend Web3 project created for demonstration and development purposes.

Live swap quotes and portfolio information depend on external Solana and Jupiter APIs.
